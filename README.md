# Lurk

Twitch and Kick in one app.

Lurk is in early development. There are no releases yet.

## What it will do

- One Following list for your Twitch and Kick channels, with live channels on top
- Browse and search both platforms at once, signed in or not
- A player with a mini-player, picture-in-picture, background audio and an audio-only mode
- Chat with 7TV emotes on both platforms (plus BTTV and FFZ on Twitch), including zero-width emotes and 7TV paints
- Optional proxy support for Twitch, using proxies you add yourself
- Light, dark and AMOLED themes, with Material You colours

## Platforms

Android comes first. An iOS version is planned after the Android app reaches 1.0.

## Install

Builds will be published on [GitHub Releases](https://github.com/kemuriXD/Lurk/releases) once the first version is ready. There is no Play Store or App Store listing, and none is planned.
