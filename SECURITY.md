# Security policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please report security problems privately through GitHub: open the Security tab of this repository and choose "Report a vulnerability". Don't open a public issue for them.

It helps to include the app version, your Android version and device, and the steps to reproduce the problem. You should get a reply within a week. Once a fix is released, the advisory is published with credit to you, unless you'd rather stay anonymous.

Never paste login tokens, cookies or session data into a report. If one of yours was exposed, sign out of Twitch or Kick on the web to revoke it.
